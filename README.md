# qa_python

## Описание проекта

Проект содержит класс `BooksCollector` и автотесты для проверки его методов.

Тесты написаны на Python с использованием библиотеки `pytest`.

## Реализованные тесты

В файле `tests.py` проверяются:

1. Добавление двух книг в коллекцию.
2. Запрет добавления книги с пустым названием.
3. Запрет добавления книги длиннее 40 символов.
4. Добавление книги с названием длиной 40 символов.
5. Установка разрешённого жанра существующей книге.
6. Запрет установки жанра неизвестной книге.
7. Запрет установки неизвестного жанра.
8. Получение жанра книги по названию.
9. Получение `None` для неизвестной книги.
10. Получение книг с определённым жанром.
11. Получение пустого списка, если совпадений нет.
12. Получение словаря книг и жанров.
13. Получение книг, подходящих для детей.
14. Исключение книг жанров «Ужасы» и «Детективы» из списка детских книг.
15. Добавление книги в избранное.
16. Запрет повторного добавления книги в избранное.
17. Запрет добавления неизвестной книги в избранное.
18. Удаление книги из избранного.
19. Удаление неизвестной книги без ошибки.
20. Получение списка избранных книг.

## Проверяемые методы

- `add_new_book`
- `set_book_genre`
- `get_book_genre`
- `get_books_with_specific_genre`
- `get_books_genre`
- `get_books_for_children`
- `add_book_in_favorites`
- `delete_book_from_favorites`
- `get_list_of_favorites_books`

`main.py` содержит реализацию класса `BooksCollector`.

`tests.py` содержит автоматизированные проверки методов класса.

`README.md` содержит описание проекта и реализованных тестов.
